# Installation — non disponible pour le moment

L'objectif est de proposer un ZIP contenant **un seul fichier `.pak`**, sans application ni installeur tiers.

Installation visée après validation :

1. Télécharger une Release publiée par ce dépôt.
2. Extraire le ZIP.
3. Copier son fichier `.pak` dans `NuclearNightmare/Content/Paks/`.
4. Démarrer le jeu et activer la langue requise selon les résultats des tests.

**Important : ce parcours n'a pas encore été validé.** Aucun fichier de patch n'est distribué. Le programme du dossier `tools/` crée seulement `Game.locres` et ne remplace pas à lui seul le système de localisation du jeu.

Pour retirer un éventuel patch autonome après sa sortie, supprimer uniquement le fichier `.pak` ajouté. Ne pas écraser l'archive originale `NuclearNightmare-Windows.pak`.

Ce projet nécessite une copie légitime du jeu et ne contient aucun exécutable du jeu ou autre ressource propriétaire.
