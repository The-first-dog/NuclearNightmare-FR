# Nuclear Nightmare — Traduction française 🇫🇷

**Traduction française non officielle de Nuclear Nightmare**, par **FantinHD**.

Ce patch ajoute le français aux textes de localisation du jeu. Il s'installe par simple copie d'un fichier `.pak`, sans logiciel externe ni installateur.

## 🇫🇷 Contenu traduit

- Interface, menus et paramètres
- Commandes et indications
- Objectifs, notifications et messages en partie

**1 463 entrées de localisation disposent d'un texte français.** La version est une candidate : des corrections de contexte ou d'affichage restent possibles.

## 📦 Installation

1. Téléchargez **[l'archive ZIP française](https://github.com/The-first-dog/NuclearNightmare-FR/raw/refs/heads/main/downloads/NuclearNightmare-FR-v1.0.0-rc.1.zip)**.
2. Dans Steam : **Bibliothèque → Nuclear Nightmare → Propriétés → Fichiers installés → Parcourir**.
3. **Fermez le jeu.** Décompressez le ZIP, puis copiez le dossier `NuclearNightmare` extrait **dans le dossier principal du jeu**. Acceptez seulement la fusion des dossiers.
4. Vérifiez la présence du fichier `NuclearNightmare/Content/Paks/NuclearNightmare-FR_P.pak`.
5. Lancez le jeu et choisissez **Russe** dans le menu des langues : cette entrée est provisoirement remplacée par le français.

Le fichier original `NuclearNightmare-Windows.pak` **ne doit pas être supprimé ni remplacé**.

📖 [Guide d'installation détaillé](docs/INSTALLATION.md)

## 🗑️ Désinstallation

Fermez le jeu et supprimez uniquement ce fichier :

```text
NuclearNightmare/Content/Paks/NuclearNightmare-FR_P.pak
```

L'archive officielle du jeu reste intacte.

## 🔐 Sécurité et transparence

- Aucun programme `.exe` ou installateur fourni.
- Un seul fichier `.pak` ajouté au jeu.
- Traduction et scripts de construction consultables dans ce dépôt.
- Sommes de contrôle SHA-256 fournies avec la Release.
- Le chargement du patch peut dépendre de la version du jeu ; **Linux/Proton n'a pas été validé**.

Il s'agit d'une traduction de fans, pas d'un mod officiel Steam Workshop.
